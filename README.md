# 🗓 Персональный AI-ассистент для Google Calendar

Умный Telegram-помощник для естественного и интеллектуального управления расписанием в Google Календаре.

##  Зачем нужен
* **Удобное управление:** Быстрый доступ к календарю прямо из мессенджера.
* **Проактивное планирование:** Бот не просто записывает задачи, а выступает в роли собеседника:
  * Обсуждает прошедший день и ближайшие планы.
  * Предлагает изменения и оптимизацию в расписании.

##  Для кого
* **Пользователи Google Calendar**, которым комфортнее и быстрее вести диалог в Telegram, чем открывать календарь и создавать события вручную.
* **Люди, которым важен контекст:** Проект выходит за рамки функции «быстро добавить встречу». Это инструмент для тех, кому нужна регулярная рефлексия над днем/неделей и адаптивная подстройка личных планов.

##  Технологии и особенности

* **Стек:** `Python`, `aiogram`, `FastAPI`
* **База данных:** `PostgreSQL` (SQLAlchemy Core) + `Alembic`
  * *Особенности:* Настроены миграции, реализована upsert-логика для безопасных частичных обновлений без потери данных.
* **Интеграция:** `Google Calendar API` + `OAuth 2.0`
  * *Особенности:* Поддержка автообновления токенов и best-effort получение часового пояса пользователя.
* **AI-движок:** `DeepSeek` (через OpenAI-совместимый SDK)
  * *Особенности:* Использование LLM с Function/Tool Calling. Для каждого вызываемого инструмента реализована строгая схема валидации через `Pydantic`.
