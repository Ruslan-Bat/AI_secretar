СЛАЙД 2. ПРОБЛЕМА
Изменение планов требует ручной перестройки расписания

Для людей с насыщенным и меняющимся графиком:
• Договорённости из переписок приходится вручную переносить в календарь.
• Рабочие и личные планы находятся в разных сервисах.
• Перенос встречи требует заново учитывать задачи, подготовку и дорогу.
• Свободный промежуток в календаре не всегда подходит для ещё одной задачи.

СЛАЙД 4. ОБРАБОТКА ЗАПРОСА
Как сообщение превращается в событие

1. Запрос
Пользователь описывает событие в Telegram.

2. Разбор
ИИ определяет действие, дату, время и длительность.

3. Уточнение
Ассистент запрашивает недостающие сведения.

4. Выполнение
Сервис отправляет запрос в Google Calendar и сообщает результат.

Планируемое расширение: голосовой ввод, проверка конфликтов и маскирование чувствительных данных перед обращением к внешней модели.


СЛАЙД 5. НАУЧНО-ТЕХНИЧЕСКОЕ РАЗВИТИЕ
Перепланирование с учётом ограничений пользователя

Планируемые НИОКР:
• Подбор времени с учётом приоритетов, подготовки, дороги и перерывов.
• Перестройка расписания с сохранением фиксированных встреч и минимальным числом переносов.
• Маскирование чувствительных данных с сохранением информации, необходимой для планирования.

Проверка результатов: соблюдение ограничений, число исправлений пользователем и качество планирования после маскирования данных.

СЛАЙД 13. ПРИЛОЖЕНИЕ A1. АРХИТЕКТУРА
Компоненты системы и поток данных

Текущий прототип
1. Telegram-бот на aiogram принимает сообщение пользователя.
2. Бэкенд на FastAPI передаёт запрос языковой модели.
3. Модель определяет действие и параметры события. При нехватке данных ассистент задаёт уточняющий вопрос.
4. Бэкенд выполняет операцию через Google Calendar API с авторизацией OAuth 2.0.
5. Пользователь получает результат операции. PostgreSQL хранит профиль и историю диалога.

Планируемые модули
• Маскирование чувствительных данных до обращения к внешней модели.
• Проверка занятости по данным календаря и подбор подходящего времени.
• Подключение Яндекс Календаря и отдельного приложения к общему бэкенду.
